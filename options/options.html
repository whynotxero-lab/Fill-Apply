Fill & Apply

Queue. Fill. Apply.

Profile, documents, and backend queue config (stored in chrome.storage.local).

Backend / runner

Modes: fill never clicks Next/Submit; ready advances multi-step forms but never final Submit/Apply; submit includes final Submit when confidently found. Auto-close never runs in fill/ready — only after submit success, keeping the last N tabs (3–10) for context. Queues: queued → applied / failed / cancelled. On Stop, the current incomplete job moves to cancelled; remaining stay queued.

Mock queue (apply URLs)

Paste one real job apply URL per line (Greenhouse, Lever, etc.). Example: https://boards.greenhouse.io/company/jobs/123. Only http/https URLs are queued — chrome-extension:, about:, and empty lines are filtered out. Saving rebuilds the queued list. Applied history is kept unless you Clear history.

Manual demo form: open demo/sample-application.html via Live Server or file://, then use Fill current page. Demo is manual-only — it can never enter the mock queue.

Documents (resume / cover)

Stored as base64 in fillApply.documents for DataTransfer attach to input[type=file] (including Greenhouse hidden inputs / Attach buttons). Prefer small PDFs.
