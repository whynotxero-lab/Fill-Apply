Fill & Apply settings

Profile, documents, and backend queue config (stored in chrome.storage.local).

Backend / runner

When mock mode is on (or base URL empty), getNextJob() serves jobs from the Mock queue URL list below (real https:// apply links). Live mode calls GET /queue/next, POST /applied/:id, GET /profile, GET /documents.

Mock queue (apply URLs)

Paste one real job apply URL per line (Greenhouse, Lever, etc.). Example: https://boards.greenhouse.io/company/jobs/123. Start opens these URLs — never the extension demo page. JSON array of URL strings is also accepted. Lines starting with # are ignored.

Manual demo form: open demo/sample-application.html via Live Server or file://, then use Fill current page. Do not use it as a Start queue target (chrome-extension:// pages cannot be injected into).

Documents (resume / cover)

Stored as base64 in fillApply.documents for DataTransfer attach to input[type=file]. Prefer small PDFs.
